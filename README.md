## Getting Started

### Prerequisites

A modern web browser. If your project uses Node.js, install [Node.js](https://nodejs.org/) as well.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Prathamesh-lole/PrathameshLole-portfolio.git
   ```
2. Navigate to the project folder
   ```bash
   cd PrathameshLole-portfolio
   ```
3. Open `index.html` in your browser, or run a local server:
   ```bash
   npx live-server
   ```

*(If you use npm: `npm install` then `npm start`.)*
